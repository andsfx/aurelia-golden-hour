AURELIA BAY: Golden Hour is an original open-world crime game set in a sun-soaked fictional coastal city. Drive and steal cars, walk crowded districts, take missions from a syndicate fixer, run from an escalating wanted level with an ABPD helicopter overhead, and save your progress. Vanilla ES modules and canvas 2D, no build step, no network, no external assets.

## Run it

```sh
node serve.ts
```
